# 多选表单功能测试指南

## 改进内容

### Reddit 社区多选
- ✅ 从下拉列表选择热门 subreddit，点击"➕ 添加"按钮
- ✅ 或在自定义输入框输入 subreddit 名称，按回车键添加
- ✅ 已选择的 subreddit 显示在列表中，可以点击 × 删除
- ✅ 支持一次性添加多个 subreddit

### GitHub 仓库多选
- ✅ 输入仓库地址（owner/repo 或完整URL），点击"➕ 添加"按钮
- ✅ 或按回车键添加
- ✅ 已选择的仓库显示在列表中，可以点击 × 删除
- ✅ 支持一次性添加多个仓库

### 批量添加
- ✅ 提交时会批量添加所有选中的社区
- ✅ 显示成功和失败的数量
- ✅ 自动刷新社区列表

## 测试步骤

### 测试 Reddit 多选

1. 启动应用：`uv run python app.py`
2. 打开浏览器访问：http://localhost:5000
3. 点击"➕ 添加社区"按钮
4. 选择社区类型：Reddit 社区
5. 从下拉列表选择 "r/python"，点击"➕ 添加"
6. 从下拉列表选择 "r/javascript"，点击"➕ 添加"
7. 在自定义输入框输入 "golang"，按回车键
8. 确认已选列表显示 3 个 subreddit
9. 点击其中一个的 × 按钮测试删除
10. 点击"添加社区"按钮提交
11. 确认显示"成功添加 2 个社区"（或剩余数量）

### 测试 GitHub 多选

1. 点击"➕ 添加社区"按钮
2. 选择社区类型：GitHub 仓库
3. 输入 "tiangolo/fastapi"，点击"➕ 添加"
4. 输入 "https://github.com/pallets/flask"，按回车键
5. 输入 "django/django"，按回车键
6. 确认已选列表显示 3 个仓库
7. 点击其中一个的 × 按钮测试删除
8. 点击"添加社区"按钮提交
9. 确认显示"成功添加 2 个社区"（或剩余数量）

### 测试表单重置

1. 点击"➕ 添加社区"按钮
2. 选择 Reddit，添加几个 subreddit
3. 切换到 GitHub 类型
4. 确认 Reddit 的已选列表被清空
5. 添加几个 GitHub 仓库
6. 点击"取消"按钮
7. 重新打开表单，确认所有选择都被清空

## 预期结果

- ✅ 可以通过下拉选择、自定义输入、回车键等多种方式添加
- ✅ 已选列表实时更新
- ✅ 可以删除已选项
- ✅ 批量提交成功
- ✅ 显示正确的成功/失败数量
- ✅ 表单重置正常工作

## 注意事项

- Reddit 和 GitHub 支持多选
- HackerNews、Discourse、其他网站仍然是单个添加
- 关键词和描述配置会应用到所有批量添加的社区
- 如果某个社区添加失败，不会影响其他社区的添加
